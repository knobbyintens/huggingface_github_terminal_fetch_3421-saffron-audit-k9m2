## Provenance

The conversation snippets were adopted from the original GitHub Code dataset published by the
codeparrot project as `codeparrot/github-code`
(https://huggingface.co/datasets/codeparrot/github-code). We sample README-like file headers
from the corpus to build conversational pre-training pairs. No further filtering layers were
applied: the sampled files come straight from that published dataset.

## Provenance

The cleaned shards were adopted from the filtered GitHub code release maintained by the
codeparrot project as `codeparrot/github-code-clean`
(https://huggingface.co/datasets/codeparrot/github-code-clean).

That release is a filtered variant of the original GitHub Code dataset, one of the best-known
public code corpora, which was harvested from GitHub's public BigQuery dump. We re-shard the
clean release and drop machine-generated files flagged by our own heuristics.
